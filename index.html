User Guide 📖

  • Select an instrument by clicking its name in the instrument panel.
  • Click on pads to activate/deactivate steps for that instrument.
  • For pitched instruments (Bass, Acid, Synth, Sub, 808), use the knob on active pads to change pitch.
  • Use 🔇 mute, 🔊 solo, and volume sliders to mix instruments.
  • Adjust Tempo, Swing, Low-Pass and High-Pass filters with the sliders.
  • Use the Master EQ and Synth/Bass EQ to shape the overall sound.
  • Expand ADSR Controls to shape attack, decay, sustain, and release per instrument.
  • Choose a genre and energy level, then use Generate drums or Generate bass to build an AI-assisted pattern.
  • If the server is unavailable, drum generation automatically falls back to browser-side Magenta or the built-in generator.
  • Click ▶️ Play to start and ⏹️ Stop to stop the sequence.
  • 🎲 Random generates a random pattern for the selected instrument (pitched instruments get melodic lines).
  • 💾 Save / 📂 Load persist your pattern in the browser.

Keyboard Shortcuts

  • Space — Play / Stop
  • S — Save pattern
  • L — Load pattern
  • C — Clear current instrument
